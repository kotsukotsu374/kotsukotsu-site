## 1. プロジェクト概要

- サイト名:**コツコツ**(英字表記:KOTSUKOTSU)
- 目的:Claude Codeで作ったホームページを起点に、AIでブログ記事とX投稿を(半)自動更新し、将来的に収益化を目指す
- テーマ:匿名のダイエット・トレーニング日記(エッセイ風)
- 発信者は**顔出し・身バレをしたくない**。個人が特定できる情報は一切公開しない前提で設計すること
- 収益化の方法はまだ未定(まずは発信を軌道に乗せることを優先)

## 2. これまでに決まったデザイン方針

- 完成済みの `index.html` が同じフォルダにあります。**このデザイントーンを崩さず引き継いでください**
- デザインの方向性:ダーク基調 × オレンジ/イエローのアクセントカラーによる、雑誌の特集ページのようなエディトリアル調。丸みや絵文字、パステルカラーは意図的に排除している
- 使用フォント:見出し・数字は Space Grotesk、本文は Zen Kaku Gothic New(Google Fonts CDN経由)
- 現状はハードコードされた仮のダミー記事(3件)とSNSリンク(ダミーhref)が入っている状態

## 3. コンテンツ運用の設計方針(重要)

ユーザーは「気づき・学び・心境のエッセイ風」の日記を書きたいが、**日々の入力はできる限り最小限にしたい**という要望がある。ただし完全自動生成(実体験ゼロ)は内容が薄くなるリスクがあるため、以下の設計を推奨:

1. ユーザーが1日1〜数行程度の短い出来事・気持ちのメモを入力する(入力手段は要検討:簡単なフォーム/テキストファイル/LINE連携など、実装しやすいものでよい)
2. その短いメモと、過去の文脈(体重推移や過去記事のトーンなど)をもとに、AI(Claude API)がエッセイ風の記事に肉付けする
3. ユーザーが軽く確認してから公開する(完全自動公開ではなく、承認ステップを挟む設計を推奨)
4. 記事公開と連動して、Xへの要約投稿を自動生成する

## 4. 次にやってほしい実装タスク(優先順)

1. **GitHub Pagesでの公開**:このリポジトリ構成をGitHub Pagesで公開できる形に整える(必要であれば `docs/` フォルダ構成やGitHub Actionsでのビルド設定などを提案)。ユーザーはGitHubアカウントを持っているか未確認なので、持っていない場合は作成から案内すること
2. **記事ページの実装**:トップページの「Recent Log」がダミーのため、実際に記事(Markdownなど管理しやすい形式を推奨)を追加・一覧表示できる仕組みを作る
3. **日々の入力 → AI記事化のワークフロー**:上記3章の設計に沿って、実装しやすい方式を提案し構築する。Anthropic APIキーの安全な管理方法(環境変数、GitHub Secretsなど)も含めて案内すること
4. **X連携**:X APIの利用条件(無料枠の制限など)を確認した上で、記事公開と連動した自動投稿の仕組みを構築する
5. **収益化の検討**:上記が安定稼働してから、アフィリエイト・広告・独自商品販売など、テーマに合った方法を提案する

## 5. 注意事項

- ユーザーはコーディング未経験。専門用語を避け、都度「何をしているか」を分かりやすく説明しながら進めること
- 匿名性を損なう実装(顔写真の使用、個人情報の露出につながる設定など)は避けること
- APIキーなどの認証情報を絶対にコードやリポジトリに直接書き込まないこと(環境変数・Secretsを使う)
